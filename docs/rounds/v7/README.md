# reed doc_v7：外部审查报告的独立核实 + 修复规范（2026-10-12）

> 本目录是 `docs/rounds/v6/` 之后的**第七轮规范**。它由两部分组成：
> 对一份外部分片审查报告（16 条高危 + 7 条中危 + 7 条低危）的**独立逐条核实**，
> 以及在核实基础上的**修复规范**。
> 本目录不修改任何代码，所有改动以规范形式给出，由实现者执行。
> 历史轮次 `docs/rounds/vN/` 只增不改；当前规范索引见 `docs/README.md`。

## 背景

一份由 7 个智能体分片并行产出、总经理逐条读码核实的审查报告（`H1–H16` / `M1–M7` / 低危若干）
声称在当前实现（约 3.8 万行）中发现了一批缺陷。该报告在其自身"覆盖缺口"一节即已声明：
reed-core/reed-io 由补位智能体产出、可信度低，且 **bgzf 虚拟偏移、tabix/csi 随机访问边界未获充分覆盖**；
另有一条高危（H15）声称"统计公式零对拍测试、oracle-parity 门不存在"。

本轮的工作是**不信任该报告的结论，逐条读码复验**，并给出可执行的修复规范。
核实采用可达性优先：既判断"代码是否真如描述"，也判断"用户是否真能触发"。

- **仍有效**：v6 的架构与路线（`docs/rounds/v6/03-architecture.md`、`06-roadmap.md`）继续有效，本轮不推翻其任何结构决策。

## 结论速览

| 维度 | 结论 |
|---|---|
| 高危 H1–H16 | **13 条成立**（含 2 条经本机对拍确认）、**1 条部分成立**（H2，"往返不等价"被高估）、**1 条核心指控被推翻**（H15，"零对拍测试"为假）、**H4 全部成立且比报告更严重**（另发现 PSC 缺 SNP 行门控） |
| 中危 M1–M7 | M1/M2/M3/M4/M5/M6 成立；M7 内部对错各半（守卫不一致成立、取整口径不成立、文档公式属记号草率） |
| 低危 | 2 条为假（"docs 引用仓库外文件""proptest 死依赖"）、2 条部分成立、3 条成立 |
| 新发现 | 4 条（PSC 无 SNP 门控、`pi.rs` 溢出门槛低、fst `h_bar` 半分型口径、gold 管道盲区） |
| 数值正确性 | oracle-parity 集成测试（`crates/reed-stats/tests/oracle_parity.rs`）**确实存在**；真正的缺口是 bcftools-stats 渲染与 LD 语义零对拍 |

## 一句话结论【据】

报告对**过滤/统计的静默失效与输出损坏**（H1、H4、H5、H6、H7、H12、H13）判断准确、必须修；
对**统计公式的量纲与分母**（H3、H11、M4 附加项）判断准确；
但其"仓库没有对拍测试"的定性（H15）**错误**——仓库有完整的 oracle-parity 集成测试与 `gold/` parity 脚本，
只是覆盖面不足。修复应以"补覆盖"而非"从零建门"为方向。
