## 背景

v10 的结论是"reed 在自己生成的数据上全对，在别人生成的边界数据上出错"，
修的是**结构**层（描述符、位宽、块长、残片）。本轮用同一把尺子量 INFO 的
**语义**层，发现同样的模式在更高一层重现：读侧（BCF → 文本）经差分夹具
验证已与 bcftools 逐字节一致；写侧的值编码（超界整数、Flag 带值、String
`.`、计数上限）与过滤语义（sketch 策略、`-q` 的 INFO 优先级、表达式的类型
盲区、无 GT 记录的重算）成族偏差。

用户复审追问"这些问题有些是因为共性代码的原因么"——是：15 条缺陷中 12 条
落在 10 个**共性代码根因簇**上（01-review §0.5）。两个元模式：

1. **同一规则的多份实现各自漂移**：AC/AN 读取 3 份、INFO 数值解析 3 份、
   ALT 计数 3 份、INFO 编辑语义文本/BCF 2 份、打包计数写回 4 处。这是
   v10 D10-1（GT 位宽两份拷贝一处错）的放大版。
2. **元数据存在但消费者没查**：`has_tail_expr`（计划算了，驱动覆盖策略时
   不看）、`has_gt`（一路传到 `SiteCounts`，`-g` 查了，重算没查）、
   `TagTable`（编译期有，表达式层只拿名字）、cohort 变化（驱动知道，
   `-q` 规则不知道）。

因此修法以**收口**为主：单一实现 + 把已有元数据传给做决定的那一行。

## 结论速览

| 维度 | 结论 |
|---|---|
| 读侧（BCF → 文本） | **已一致**：差分夹具逐字节相同；`%g` 浮点、`-q :type` 五种、有 GT 的子集更新均与 bcftools 1.24 对拍通过。`render.rs` 主路径经受住对照 |
| 写侧值编码（D12-3/4/5/9，P1/P2） | 超界整数回绕（htslib 置 missing）、Flag 带值丢失且 `DB=0` 反转（htslib 按字符串存）、String `.` 变空串（htslib 字面存）、打包计数溢出写坏文件（htslib 解析期拒绝）。修法收口成"值 × 声明类型"单一编码函数 + 计数上限 helper |
| 过滤语义（D12-1/2/6/7/8/10/13，P0/P1/P2） | sketch 策略丢行字段（守卫在 plan、覆盖在驱动，两处脱节）；无 GT 记录被清零（`has_gt` 没传给重算）；`-q` 用陈旧 INFO（cohort 门缺失，bcftools 两处同款门）；表达式拿不到类型（Flag/向量/裸标签三类与 bcftools 相反）；`any` 量词不看比较结果；`ALT='.'` 计数三份实现只有一份对 |
| 契约可见性（D12-11/12，P2） | `--fill-tags` 承诺 AF/F_MISSING 未实现且不校验（bcftools 报错退出）；默认 `-x` 删 8 个标签在 help/README/cli.md 均无提示 |
| 共性代码（01 §0.5） | 12/15 条缺陷落在 10 个根因簇；修法是收口（单一实现）+ 把已有元数据（`has_tail_expr`/`has_gt`/`TagTable`/cohort）传给消费者 |
| **规范量尺（01 §2.5，VCFv4.5 草案）** | INFO 解析**全为 reed 自写**（D1 决策，不经 noodles；noodles 只剩 header/索引/渲染/BCF-oracle 四用）。对照 4.5 草案后：D12-3 升格为**规范明文**（`[−2³¹,−2³¹+7]` 在 VCF 与 BCF 都被禁止，tex:101）；Flag 带值/Number=1 多值属**规范外输入**（恢复策略对齐 htslib / reed 自选 missing）；`+5` 是**合法输入**（Float 正则 `[-+]?`，N13 顺手对齐）；B4 理由**更正**（4.5 起值可含空格，不 trim 的依据改为"数值文法无空白"）；D12-9 夹具的重复键属规范外（红测试改用互异键）。**对齐判定**：18 条必须对齐（A1–A18）、**8 条标注不改**（B1–B8，永久分歧只登记 cli.md）、5 条待拍板（C1–C5） |

## 与 v10、v11 的关系

- v10 修结构层（描述符/位宽/块长/残片），本轮修语义层（值编码/编辑重算/
  过滤判定）；D12-9（打包计数）是 v10 D10-8（checked 乘法）同族缺口的
  补全，D12-3/4/5 与 D10-1 同模式（"两份拷贝/无值域检查 → 静默截断"）。
  v10 §4"本轮不做"的 `bcf_record_check` 全量移植维持不做。
- v11 是门面 API 轮（`reed` 公开面），与本轮正交；两轮无共享文件
  （v11 动 `lib.rs`/`request.rs`/`render.rs`(stats)/`error.rs`，本轮动
  `native_encode.rs`/`line_edit.rs`/`expr`/`plan`/`filter` 驱动），可并行
  落地，合并顺序无关。
- §11.4 的三策略等价契约（architecture.md:1762"输出 sha256 相同"）是
  D12-1 的判据来源；既有测试夹具没覆盖"尾部表达式读行字段"，R0-a 补上。

## 决策状态

| 决策 | 状态 |
|---|---|
| 裸标签（无比较符）的处置（N6 §3）：对齐 bcftools 恒假，还是编译期拒绝 | **待拍板**；规范默认**编译期拒绝**（错误优于静默恒假，且符合 cli.md §5"报告而非另一种语义执行"的纪律） |
