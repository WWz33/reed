## 总结（立项时）

- **确认未修：**mmap unsafe 合同、BGZF footer 信任、AC 求和溢出、线程数上界、重复 INFO 标签语义分叉、BCF `n_allele=0` 接受、VCF 空必需字段验证缺口、跨 chunk carry 与 PCA dense 内存低估、输出非原子覆盖、容器内存探测、noodles 边界/版本锁定、PCA/faer 并行超出线程预算。
- **验证门缺口：**gold parity 工作流没有在 parity 步骤构建并生成 reed 产物；当前仓库声明 MSRV 1.91，但常规 CI 只用固定的 Rust 1.99。
- **测试风险：**spill 编号耗尽测试和其他递增全局计数器的测试共用编号；2026-11-05 默认并行单测再次复现竞争失败，串行通过。
- **旧候选更正：**`--hwe midp` 明确拒绝是文档化的未实现能力，不是缺陷；`N_MISSING` 计完全缺失基因型，而 `-g miss` 将 half-call 归为 missing，是不同且已记录的语义，不作为 v26 bug；`reed-reduce` 有解析器/算法单测，不能再称"测试为空"。R8/R9 暂列待复现，不预判成立。

## 总结（实施后）

- **全部 P0/P1 已修**：V26-00…V26-10、V26-13、V26-20、V26-21；V26-11/12/14 的 CI 与测试缺口已补；V26-17 并入 V26-08。
- **两项在测量后不改**：V26-18（1 TiB 输入才 ~39 MiB 元数据，ring 化无实测收益）、R8/R9（核对后一致，非缺陷）。
- **验收**：1055 项测试全绿、clippy 0、doc-drift 97/97、structure 16/16、MSRV 1.91 实测通过、7 GB 真实数据记录数不变、`kill -9` 原子性实测。
- **有意留下的非承诺**：多文件输出的整组事务性、`--hwe midp`、`--memory` 作为进程 RSS 上限。三项都写进了对应 spec。
